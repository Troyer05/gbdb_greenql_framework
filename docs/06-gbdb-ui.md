# GBDB UI

The UI is available through `PHP/gbdb_ui.php` and is routed internally through `PHP/gbdb_framework/public/index.php`.

## Areas

- Dashboard
- GreenQL Studio
- GreenQL Scripts
- PHP Exec
- Users
- ENV
- Plugins
- Migration
- Crypt
- Optimize
- Backup
- Enterprise
- Monitoring

## Enterprise Pattern Manager

The Enterprise page can now install JSON patterns into a manually chosen instance and can create, edit, delete, activate and deactivate patterns.
